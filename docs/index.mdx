# Normies Documentation

Normies is a desktop app that turns ideas into working software — without requiring you to know how to code. You describe what you want in plain English. Normies figures out the best approach, builds it, tests it, and hands it off with a plain-language guide.

## How Normies Works

Every project follows the same flow:

1. **Explore** — Describe your problem. Normies asks follow-up questions until it truly understands what you need.
2. **Recommend** — Before building anything, Normies checks if an existing tool already solves your problem. If so, it'll tell you.
3. **Plan** — When custom work is needed, you get a visual plan with numbered tasks, time estimates, and an architecture diagram.
4. **Build** — Each task runs in its own session with fresh context. Tests are written before code. Every task verifies its own work.
5. **Handoff** — You get a plain-language guide explaining what was built, how to verify it, and how to change things later.
